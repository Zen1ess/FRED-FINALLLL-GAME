# FRED 项目 Context Document

> 用途：这是《FRED：最后一段广播》游戏项目的工作上下文。将本文件交给新的 AI、队友或开发者时，可以直接使用它理解项目目标、剧情、视觉方向、当前实现和修改边界。

最后更新：2026-08-14

## 1. 项目一句话

《FRED》是一款约15—20分钟的像素风横版叙事游戏：13岁的Fred穿过一座被战争摧毁的小镇，逐渐发现自己并不只是身处战争现场，而是在多年后重新经历战争记忆；最终他不再逃避黑雾般的创伤，坐在现实中的椅子上听见普通的清晨声音。

核心句：战争结束于过去，和平发生在此刻。

## 2. 主题与隐喻

“Fred”使用四层含义：

1. 主人公的名字。
2. 瑞典语中“和平”的含义。
3. 战争结束后，人的内心不一定已经平静。
4. Fred最终获得继续生活的能力，达到迟来的内心和平。

黑雾不是一个需要被武力消灭的敌人，而是战争记忆、幸存者内疚、恐惧和自我否认的具象化。

最终目标不是“删除记忆”，而是让Fred不再被记忆支配。

## 3. 叙事设定

- 表面时间：二战末期。
- 真实时间：多年后的停战纪念日清晨。
- 地点：不明确国籍的虚构欧洲小镇。
- 主人公：少年Fred，约13岁。
- 结局人物：老年Fred，只坐在扶手椅上，不站立、不奔跑。
- 其他人物：不出现完整身体，主要通过广播、纸条、外套、墙面影子和幻听存在。
- 核心锚点：同一台旧收音机贯穿家、避难所、广场和结局现实房间。

## 4. 场景流程

当前游戏有8个场景：

1. **爆炸前的家**：收音机零件拼图、空袭选择、爆炸震动和废墟逃生。
2. **无人的住宅街**：调查哭声、飞机阴影、红手套和绿色出口标志。
3. **被洗劫的杂货铺**：面包选择、镜中老人伏笔、现代卡片彩蛋。
4. **临时诊所**：低亮度暖白灯闪烁、空床、名单碎片和年龄“13/83”伏笔。
5. **废弃学校**：儿童画六块碎片拼图、黑板上的和平问题、现代疏散图。
6. **地下避难所**：调频、自动服药提示、简化声音迷宫和黑雾追逐。
7. **钟楼广场**：打开撤离通道后黑雾出现，空袭躲避和最终面对黑雾。
8. **现实中的清晨房间**：老年Fred坐在椅子上，调开战争广播，听见普通晨间频道。

## 5. 选择与雾值

游戏共有13道选择题。每个选项对应隐藏雾值M：

- 面对、承认、尝试理解：M + 0
- 犹豫、暂时回避：M + 1
- 否认、封闭、被恐惧支配：M + 2

这不是对玩家进行道德评分，只表示Fred在本次回忆中受到创伤影响的程度。

场景中调查现代物品可获得“现实回声E”：

`最终侵蚀值X = max(0, M - E)`

Boss表现：

- X为0—7：低侵蚀，攻击节奏慢，安全位置明显。
- X为8—15：中侵蚀，飞机阴影和黑雾正常变化。
- X为16以上：高侵蚀，画面更暗，重复语句更多，躲避压力更强。

结局不因数值锁死。所有路线都应能完成主线。

## 6. 声音迷宫：当前设计

声音迷宫借鉴“第一人称节点移动、方向选择、错误路线形成循环、可展开地图”的解谜结构，但保持原创并简化。

### 玩法

- 进入避难所并完成调频后，玩家接近隧道即可按E打开声音迷宫。
- 每个房间有三个方向：左侧、前方、右侧。
- 玩家把鼠标移到方向按钮上，会试听一段短促声音。
- 正确方向的声音更清晰、更高；错误方向只有墙壁低鸣。
- 正确路径共4步：`forward → left → right → forward`。
- 走错会回退一格，并增加“折返”次数。
- 第一次走错后，右侧的4×4简化地图解除模糊，显示已走过节点。
- 完成4步后关闭迷宫，播放广播，再进入黑雾追逐。

### 当前实现位置

- `maze`：路径、节点、房间图标和错误次数。
- `startSoundMaze()`：初始化并显示迷宫。
- `renderMaze()`：渲染节点地图与三方向按钮。
- `previewMaze()`：试听方向并更新声音强度条。
- `chooseMaze()`：判断方向、回退、震动和成功流程。
- `mazeTone()`：使用浏览器 Web Audio 生成短音调。

### 后续可扩展但非必须

- 给每个房间增加不同的环境声，例如空床摩擦、木梯声、衣架碰撞、出口风声。
- 增加“地图纸”收集动画。
- 将方向按钮换成像素箭头或鼠标点击场景左右边缘。
- 让高雾值时错误方向的声音更像母亲呼唤，增加心理误导。

## 7. 视觉方向

参考的是以下视觉特征，而不是复制具体作品：

- 战争绘本式的手绘线稿、分层废墟、低饱和灰绿和局部暖光。
- 横版叙事游戏的远景、中景、可玩地面和前景遮挡。
- 阴暗童话式的大头、瘦肢、过大外套和孤独剪影。
- 更明显的像素颗粒、方块边缘和有限色板。

不得直接复制任何参考游戏的角色、建筑、UI、构图、文字或独特道具。

当前原创素材：

- `assets/fred-ruins-bg.png`：原创废墟住宅街主背景。
- `assets/fred-character-sheet.png`：透明背景Fred五姿势角色表。
- `assets/fred-character-source.png`：角色表生成时的洋红背景源文件，仅作为中间素材保留。

角色表姿势顺序：

1. 静止侧面。
2. 行走接触帧。
3. 行走通过帧。
4. 操作收音机。
5. 捂住耳朵。

## 8. 特效规则

当前已经实现：

- 场景淡出、切换、淡入。
- 选择后短暂停顿和选项高亮。
- 开场爆炸震屏、闪白和落尘扩散。
- 受击震屏。
- 住宅街的飞机阴影。
- 诊所低亮度暖白闪烁。
- Boss阶段横向扫描噪点。
- 灰尘粒子、前景遮挡和角色脚下阴影。
- 互动目标的暖色脉冲标记。

特效要服务于叙事，不要持续使用强烈闪烁。诊所灯光必须是低亮度暖白，而不是冷白强光。

## 9. 代码结构

- `index.html`：游戏容器、标题页、对话框、选择题、拼图、调频和声音迷宫UI。
- `script.js`：场景状态、选择题、雾值、角色绘制、特效、解谜、声音迷宫、Boss和结局。
- `styles.css`：页面外框、像素游戏UI、对话、选择、拼图和调频样式。
- `assets/`：原创背景、角色表和已有图片资源。

重要函数：

- `reset()`：重置游戏。
- `say()`：显示对话并等待E/Enter。
- `ask()`：显示选择题并累计M。
- `offerInteraction()`：设置靠近物体后的E互动。
- `sceneEvent()`：根据场景和Fred位置触发互动。
- `nextScene()`：使用淡出淡入切换场景。
- `draw()`：主画面绘制和特效叠加。
- `drawPixelPerson()`：角色表切帧和备用程序角色。
- `finish()`：进入坐姿老年Fred结局。

## 10. 运行方法

### 直接打开

双击根目录中的 `index.html`，或在浏览器地址栏打开本地文件。

### 操作

- A/D或方向键：移动。
- E或Enter：推进对话、主动调查、打开通道。
- 鼠标：选择答案、拖动调频、操作拼图、选择声音迷宫方向。
- 声音迷宫：把鼠标悬停在左、前、右方向试听，再点击最清晰的一侧。

建议使用耳机，因为声音迷宫通过音高、响度和杂音差异传达线索。

## 11. 修改约束

后续修改时必须保持：

- 老年Fred只在结局出现，始终坐着。
- 不添加大量可见配角，人物主要通过声音和物品存在。
- 不把黑雾变成普通可射击敌人。
- 不使用现代物品过早直接解释谜底。
- 不让选择题出现唯一“道德正确答案”。
- 不用高亮白光破坏诊所的深色氛围。
- 不复制参考作品的角色、UI或场景。
- 新增互动应有缓冲：动画、短音效、停顿或淡入淡出至少保留一种。
- 场景切换必须通过 `nextScene()`，不要直接修改 `game.scene`，否则会跳过淡入淡出和章节提示。

## 12. 验收清单

提交前检查：

- 能从标题页开始并完整到达结局。
- 13道问题均可以触发，雾值会变化。
- 每个主要互动需要玩家按E，不是靠近就自动完成。
- 声音迷宫正确路线可以通关，错误路线会回退。
- 调频可以听到“早上八点，请按时服药”。
- 诊所使用深色背景和低亮度暖白闪烁。
- 飞机阴影、爆炸震动和Boss震动正常出现。
- 角色表加载失败时仍有程序绘制的备用Fred。
- 角色表透明角落保持透明，不能出现洋红背景。
- `script.js`通过Node语法检查，`git diff --check`没有空白错误。
